# SBEG 46X Medical Robotics — Course project (team repository)

Starter code for the course project. Read the **Project brief**, **Scenario sheets** and **Rubric** in the
course's *Course Project* folder (course site). One repository per team (Classroom 50 team assignment).

```bash
python -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q        # baseline and model checks; your team's tests are skipped until you implement them
```

See `README_STARTER.md` (the original starter guide) for the modules, the hardware-log format and the commands.
AI use is allowed with disclosure (AI-use appendix in the report); every member defends the work in the oral defence.
