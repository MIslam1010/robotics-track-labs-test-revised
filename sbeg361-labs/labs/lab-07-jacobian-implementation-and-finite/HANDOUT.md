## Why this lab matters

Every velocity, force and IK computation in the rest of the course goes through the Jacobian. A Jacobian is also easy to get *almost* right: a sign, a missing $\omega\times p$ or an adjoint in the wrong direction gives numbers that look plausible. In this lab you build the Jacobians from the screw axes (MR Eqs. 5.11 and 5.18) and then **prove** them right with independent checks — finite differences of the forward kinematics and the official `modern_robotics` library. Two cases drive the lab:

* **Biomedical — instrument-tip speed in teleoperated needle placement.** The course arm with the 0.06 m needle guide (project scenario S3, `desktop_6r`) is moved by a surgeon through a master device. A recorded joint trajectory (`teleop_needle.csv`, synthetic) contains a 9 Hz physiological-tremor component that leaks through the motion scaling. You compute the needle-tip velocity with the Jacobian and check it against an illustrative safety limit of **0.05 m/s**.
* **Defence — wrist singularity of an EOD manipulator.** The 6R arm of a tracked explosive-ordnance-disposal robot (`eod_6r_ugv`, scenario S4; Workshop Problem 4) loses rank when its two roll axes line up. You show that $J_s$ and $J_b$ lose rank together and track the smallest singular value as the wrist approaches the singularity.

All robot numbers are those of the course robot models (Course resources: Course robot models and hardware safety checklist), copied into `data/robots.json`; geometry is illustrative unless it is a textbook robot.

# Procedure and checkpoints

### Checkpoint 1 — Geometric Jacobians (≈ 15 min)

1. `jacobian_space(Slist, theta)`: column 1 is $\mathcal S_1$; accumulate $T = e^{[\mathcal S_1]\theta_1}\cdots e^{[\mathcal S_{i-1}]\theta_{i-1}}$ and set $J_{si} = [\mathrm{Ad}_T]\mathcal S_i$ (MR Eq. 5.11).
2. `jacobian_body(Blist, theta)`: the mirror image, from joint $n-1$ down to 1 with $e^{-[\mathcal B_{i+1}]\theta_{i+1}}$ (Eq. 5.18).
3. `body_from_space`, `space_from_body` (Eqs. 5.22–5.23) and `point_jacobian(Js, p)`: the $3\times n$ matrix with $\dot p = v_s + \omega_s\times p = (J_v - [p]J_\omega)\dot\theta$.

**Checkpoint values.** Course arm at $q_\text{home} = (0, -0.6, 1.4, -2.4, -1.57, 0)$: $\det J_s = \det J_b = -2.422\times10^{-3}$. Needle-guide arm (`desktop_6r`) at $(90^\circ, 0, \dots, 0)$: $J_b$ equals the body screw list (Workshop Problem 3c). EOD arm at $(0, -60^\circ, 60^\circ, 0, 0, 0)$ (shoulder at its $-60^\circ$ limit): columns 4 and 6 of $J_s$ are both $(1,0,0,0,0.8928,0)$ and both Jacobians have rank 5 (Workshop Problem 4). The planar 2R with $L_1 = L_2 = 1$ at $(0, \pi/4)$ gives the point Jacobian $\begin{bmatrix}-0.7071&-0.7071\\1.7071&0.7071\end{bmatrix}$ of MR p. 171.
Tests: `test_jacobian_*`, `test_first_and_last_columns`, `test_mr_example_5_2_rrrp`, `test_dependence_on_joints`, `test_space_body_relation`, `test_point_jacobian_*`.

### Checkpoint 2 — Finite-difference verification (≈ 15 min)

1. `fd_jacobian_space(fk, theta, h, scheme)`: for each joint, $\partial T/\partial\theta_i \approx \big(T(\theta+he_i) - T(\theta)\big)/h$ (forward) or $\big(T(\theta+he_i) - T(\theta-he_i)\big)/(2h)$ (central); column $i$ = `se3_to_vec`$\big(\tfrac{\partial T}{\partial\theta_i}T^{-1}\big)$ because $[\mathcal V_s] = \dot TT^{-1}$ (MR Eq. 3.74). Raise `ValueError` for an unknown scheme.
2. `fd_jacobian_body`: the same with $T^{-1}\tfrac{\partial T}{\partial\theta_i}$ (MR Eq. 3.69).
3. `log_jacobian_space(fk, theta, h)`: column $i$ = `se3_to_vec`$\big(\log(T(\theta+he_i)T(\theta)^{-1})\big)/h$.
4. `fd_error_study(fk, J_exact, theta, hs, scheme)`: the max-abs error for each $h$.

**Checkpoint values** (course arm, $\theta = (0.3, -0.7, 1.2, -1.9, -1.2, 0.5)$): at $h = 10^{-3}$ the forward error is $1.41\times10^{-4}$ and the central error $1.67\times10^{-7}$. Over $h = 10^{-1}\dots10^{-3}$ the fitted slopes are 1.00 (forward) and 2.00 (central). Sweeping $h$ from $10^{-1}$ to $10^{-10}$, the smallest forward error is about $5\times10^{-9}$ (at $h\approx3\times10^{-8}$) and the smallest central error about $2\times10^{-11}$ (at $h\approx3\times10^{-6}$); below these the error **grows** again. `log_jacobian_space` is exact to about $10^{-15}$ even with $h = 0.5$.
Tests: `test_fd_*`, `test_log_jacobian_is_exact`.

### Checkpoint 3 — Analytic Jacobian (≈ 10 min)

# Troubleshooting

| Symptom | Likely cause and fix |
|---|---|
| `jacobian_space` correct only in column 1 or at $\theta = 0$ | You applied $[\mathrm{Ad}]$ with $T$ including joint $i$ itself, or did not accumulate the product. Column $i$ uses joints $1\dots i-1$ only. |
| `jacobian_body` matches `mr` for the planar arms but not the 6R arms | Order of the product: $e^{-[\mathcal B_n]\theta_n}\cdots e^{-[\mathcal B_{i+1}]\theta_{i+1}}$, built from the end of the chain. Check the sign of the exponent. |
| `body_from_space` off by a frame | Use $[\mathrm{Ad}_{T_{bs}}] = [\mathrm{Ad}_{T_{sb}^{-1}}]$, not $[\mathrm{Ad}_{T_{sb}}]$ and not its transpose. |
| Point Jacobian wrong by $\omega\times p$ | $\dot p = v_s + \omega_s\times p$, i.e. $J_v - [p]J_\omega$ (minus sign because $\omega\times p = -[p]\omega$). |
| Finite differences agree only to $10^{-3}$ | The forward difference with a large $h$; use central differences, or $h\approx10^{-5}$. |
| FD error gets *worse* for $h < 10^{-7}$ | At the Checkpoint 2 configuration (no joint at 0) this is expected round-off ($\approx\varepsilon/h$, $\varepsilon\approx2\times10^{-16}$). Report it; do not "fix" it. |
| FD error of order 1 (a whole column wrong) for $h < 10^{-6}$ | A joint sits at exactly $\theta_i = 0$ (e.g. `q_home`, where $\theta_1 = \theta_6 = 0$): `matrix_exp6` here and `mr.MatrixExp6` treat rotations below $10^{-6}$ rad as zero (`TOL`, `NearZero`), so the perturbation is lost. Not round-off: use central differences with $h = 10^{-5}$ to $10^{-4}$ (lecture notes WE-B7). |
| `fd_analytic_jacobian` disagrees with Eq. 5.25 at some configurations | $\|r\|$ is close to $\pi$, where the log jumps; the test skips those configurations, and so should your Table 1. |
| `ModuleNotFoundError: starter` | Run `pytest` from inside your Lab code folder, or set `LAB_IMPL` to your file name without `.py`. |

# Pre-lab answers (for self-check)

1. $J_{s2}$ depends on $\theta_1$ only (Eq. 5.11); $J_{b2}$ depends on $\theta_3$ only (Eq. 5.18).
2. $[\mathrm{Ad}_T] = \begin{bmatrix}R&0\\ [p]R&R\end{bmatrix}$; not orthogonal in general (its inverse is $[\mathrm{Ad}_{T^{-1}}]$, MR Eq. 3.78, not its transpose); determinant $(\det R)^2 = 1$.
3. $\dot p = v_s + \omega_s\times p = 0 + \hat z\times(0.2,0,0) = (0,\ 0.2,\ 0)$.
4. Forward (first order): about $3\times10^{-4}$. Central (second order): about $3\times10^{-7}$.
5. Subtracting two nearly equal numbers loses digits: the round-off error grows like $\varepsilon/h$ while the truncation error shrinks like $h^2$ (central). The total is smallest near $h\approx\varepsilon^{1/3}\approx10^{-5}$ for central differences ($\approx\varepsilon^{1/2}\approx10^{-8}$ for forward).

| `cpp_support not found` | the course folder `cpp_support` is not next to / above your Lab code folder | copy it there, or configure with `-DSBEG_CPP_SUPPORT=<path>` |
| `No CMAKE_CXX_COMPILER could be found` | no C++ compiler installed | install it (see Requirements); on Windows run from the "x64 Native Tools Command Prompt" if Ninja cannot find `cl` |
| `cannot open file: .../cpp_cases.json` | Lab code folder moved after configuring | delete the `build` folder and configure again |
| `jacobian_body` fails with "Eigen: wrong matrix size or index out of range" | unsigned loop counter in `for (i = n - 2; i >= 0; --i)`: it is always $\ge 0$ and wraps around | use `Eigen::Index` (signed), as in the hint |
| Wrong results only after `auto J = A * B;` | `auto` keeps an Eigen expression, not a matrix | write the type: `Eigen::MatrixXd J = A * B;` |
| `test_fd_bad_scheme_raises` fails with "threw a DIFFERENT exception" | wrong exception type | `throw std::invalid_argument(...)`, not `std::runtime_error` |
| Tests still show your old result | program not rebuilt | `cmake --build build` before `./build/lab_tests` |
